关于芯测

武汉芯测电子科技有限公司成立于2021年，立足武汉，面向全国，专注 FPGA 加速卡与工业数据采集方案的研发与交付。

公司基于 AMD/Xilinx 自适应计算平台，向客户提供从板卡选型、方案设计、定制开发到批量交付的完整服务，助力行业客户快速构建高性能计算与数据采集系统。

我们坚持诚信经营、以技术为本，与上下游合作伙伴共建长期稳定的供应与协作关系。

    FPGA 加速卡与工业采集方案
    基于 AMD/Xilinx 自适应计算平台，面向数据中心加速、边缘 AI 推理、通信协议处理与工业测试测量场景，提供板卡选型、定制开发与批量交付。以下为核心板卡方向，规格可按需定制。
    FPGA 加速卡方案
    ZU19EG 采集 / 加速卡
    Zynq UltraScale+ · XCZU19EG
    • 约 114 万逻辑单元，PS+PL 全可编程架构
    • PCIe Gen3 ×16 主机接口，DDR4 大容量缓存
    • 多路 QSFP28 / GT 高速串行接口
    • ARM 处理器硬核，板载系统实时处理
    典型应用：高速数据采集、雷达与通信、协议加速
    VU37P 超大规模加速卡
    Virtex UltraScale+ · XCVU37P
    • 约 283 万逻辑单元，8GB HBM2 大带宽内存
    • PCIe ×16 高速主机通道
    • QSFP-DD 网络接口，适配高速数据吞吐
    • 支持多卡集群与大规模并行计算
    典型应用：数据中心加速、金融低延时、基因计算
    VE3858 边缘 AI 加速卡
    Versal AI Edge · XCVE3858
    • AI 引擎阵列 + 标量/矢量/自适应硬核
    • 低功耗边缘推理与实时信号处理
    • 自适应逻辑，支持算法快速迭代
    • 工业级温度与可靠性设计可选
    典型应用：边缘 AI 推理、机器视觉、实时控制
    VM1802 通信加速卡方案
    Versal Prime · XCVM1802
    • 约 197 万系统逻辑单元，1968 个 DSP 引擎
    • PCIe Gen4 ×16 硬核（CPM，带 DMA）
    • 44 路 GTY 收发器，速率至 32.75 Gb/s
    • 4×100G 多速率以太网 MAC，片上 NoC 互联
    • Arm A72 + R5F 处理器系统，DDR4 大带宽缓存
    典型应用：5G 通信基带、网络协议加速、软件无线电
    高速数据采集卡方案
    高速 ADC 采集卡 · 1.25GSPS 双通道
    PCIe Gen3 ×8 · 14bit / 1.25GSPS
    • 2 通道同步采样，14bit @ 1.25GSPS
    • 模拟输入带宽 DC~1GHz，AC / DC 耦合可选
    • PCIe Gen3 ×8 主机接口，板载 DDR4 FIFO 大容量缓存
    • 外部触发 / 外参考时钟输入，支持多卡级联同步
    典型应用：雷达与电子对抗、超宽带信号侦测、瞬态波形捕捉
    高速 ADC 采集卡 · 250MSPS 四通道
    PCIe / 千兆网 · 14bit / 250MSPS
    • 4 通道全同步采样，14bit @ 250MSPS
    • 输入量程 ±1V / ±5V 可选，DC / AC 耦合
    • 连续采样 / 有限点 / 预触发 · 后触发 · 延时触发
    • 板载缓存 + 长时连续采集可流盘至 SSD 阵列
    典型应用：超声与无损检测、多工位并行测试、局部放电监测
    高精度同步采集卡 · 125MSPS 双通道
    14 / 16bit · 低噪声前端
    • 14bit / 16bit 分辨率可选，1 / 2 / 4 通道同步
    • 低噪声模拟前端，高 SNR 与 SFDR
    • 板载时钟管理，通道间 ps 级同步
    • 内 / 外时钟与内 / 外触发灵活切换
    典型应用：激光雷达、光电探测、精密测量与科学实验
    FMC 采集子卡与定制模块
    FMC-LPC / HPC · 可插载卡
    • 标准 FMC 接口，直插 ZU19EG / VM1802 等载卡
    • ADC + DAC 组合可选，收发一体设计
    • 外部触发与时钟同步，支持多子卡并行
    • 工业级温度等级（-40℃ ~ +85℃）可选
    典型应用：科研原型验证、通信与雷达收发、算法验证平台
    软件与开发支持：全系列采集卡提供上位机软件与 SDK，支持 Windows / Linux 及国产操作系统，提供 C/C++、Python、LabVIEW、MATLAB 接口与 DEMO 例程；支持基于 AMD/Xilinx 平台的 FPGA 固件二次开发，可按需集成抽取滤波、数字下变频（DDC）、峰值检测、累加平均等板载算法，实现采集、处理、传输一体化。
